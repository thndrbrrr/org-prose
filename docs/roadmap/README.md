# Roadmap

Using this directory: each item here is planned but not built. Bigger items have a design
document of their own in this directory, recording what was found, discussed and agreed, and
what is still open, so the work can be picked up from the document alone. Small items are just a
row. When an item is built, remove its row and document and describe the feature in the
top-level `README.md`.

## Prose and noprose

| Item | Status | Document |
|------|--------|----------|
| A `#+begin_prose` … `#+end_prose` block that sets its contents as prose inside an entry that isn't, for exercises in the middle of a section body | idea | [prose-block.md](prose-block.md) |

The block builds on the `prose` and `noprose` tags, where the tag nearest to an entry decides.
